# Marketing

Pick this for landing pages, product pages, pricing pages and launch announcements: pages read once, quickly, by someone deciding whether to care.

Do not pick it for the product itself.

## What changes from base

**Hierarchy.** The display size jumps to 64px (40px on small screens) and is used once per page. The gap between display and body is the point: a reader should know what to read first from across the room.

**One accent.** A burnt orange, 5.72:1 against white. It marks the primary action, and you get two more uses. Everything else is neutral. If a second colour seems necessary, the hierarchy is unclear and colour will not fix it.

**Section rhythm.** Sections are separated by 96px, with 128px after the hero. Inside a section, heading to body is 16px and body to action is 32px. The inside gaps are always smaller than the outside gaps, so sections read as units.

**Effects.** Still no gradients and no glass. Shadows only on floating layers. I left these off on purpose, because they are the first thing that makes a page look like every other page. If a brand needs a gradient, set `effects.gradients` to `true` in a copy of this file and say where it is allowed.

## Rules for the agent

- Write the headline before choosing a layout. If the headline could sit on a competitor's page, rewrite it.
- The hero contains a headline, one or two sentences, one primary action, and the product. Show the real product, not an abstract shape.
- Vary the sections. Three feature cards in a row, then three more, is a template. Use a wide image, a two-column comparison, a single quote, a table.
- Body text is left-aligned. A headline may be centred only if it is under two lines.
- Every section earns its place by answering a question a buyer has. "What is it", "Does it work with my stack", "What does it cost".
- Social proof uses real names and real numbers, or it is left out.
- One primary action per screen height. Repeat the same action down the page; do not introduce new ones.
- Icons must carry meaning. A row of decorative icons above feature titles is removed.
